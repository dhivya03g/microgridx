# Demand Forecasting Module

This module predicts future electricity demand using an LSTM neural network.

Dataset:
UCI Household Power Consumption Dataset

Model:
LSTM (TensorFlow/Keras)

Input:
Historical power consumption readings

Output:
Predicted future demand (kW)

Files:

* train_lstm.py
* predict.py

Sample Output:
Predicted Future Demand: 0.94 kW
